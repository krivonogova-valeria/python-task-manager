# Python Task Manager

Консольный менеджер задач на Python: добавление задач, просмотр списка и отметка выполненных.

## Запуск

python src/main.py

## Тесты

pip install -r requirements.txt
pytest

## Пример работы

После запуска программы появится меню. Введите 1, чтобы добавить задачу, 2, чтобы посмотреть список, 3, чтобы отметить задачу выполненной, 0, чтобы выйти.
