# Python Task Manager

## Описание проекта

Python Task Manager — консольное приложение на Python для управления списком задач.
Программа помогает вести учёт дел: добавлять новые задачи, просматривать их список,
менять статус и удалять выполненные или ненужные.

## Возможности

| Функция | Описание |
|---------|----------|
| Добавление задач | Создание новой задачи с названием |
| Удаление задач | Удаление задачи из списка |
| Просмотр списка | Вывод всех задач с их статусом |
| Изменение статуса | Отметка задачи как выполненной |

## Установка

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/ВАШ_ЛОГИН/python-task-manager.git
   cd python-task-manager
   ```

2. Создайте и активируйте виртуальное окружение:

   ```bash
   python -m venv venv
   venv\Scripts\activate
   ```

3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

## Запуск

```bash
python src/main.py
```

## Использование

Пример работы с программой:
